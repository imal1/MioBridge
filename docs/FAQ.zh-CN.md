# 常见问题

### 哪些端口需要开放？

控制台 3000/tcp、子服务器 Agent 3001/tcp、SSH 和协议内核实际端口。Agent 可仅允许主控 IP。主机防火墙和云安全组都要配置；先运行 `miobridge doctor`，再在服务器详情运行诊断。

### 为什么需要 root？普通用户能用吗？

安装系统服务或写入系统目录需要相应权限。可使用拥有所需权限的普通 SSH 用户及用户级 systemd/Linger。root 密码仅用于首次安装专用 SSH 公钥，验证后丢弃；后续操作使用主控密钥。密钥配置失败时可重试，或编辑档案补充凭据。

### 233boy 是什么？

这是 sing-box、Xray 和 V2Ray 的第三方安装与配置脚本集合。MioBridge 可以读取这些脚本管理的协议配置和 `url` 输出；Agent 只采集链接，不承担主控订阅转换。已有兼容配置不必重装。

### 为什么显示“部分成功”？

订阅文件已发布，但某些来源不可读、使用了离线缓存，或 mihomo 校验不可用。任务详情保留实际警告。仅主控未配置本机来源不会造成警告。发布数量突降则显示“已阻止”，旧文件保持不变；检查新增/移除列表后才手动强制发布。

### 子服务器离线会怎样？

主控保存每台服务器最后成功采集的来源，默认最多使用 72 小时。离线时继续发布这些来源并标记采集时间；超过时限后移除候选来源，并由默认 30% 数量突降保护检查是否允许发布。主动暂停或删除服务器会从比较基线排除该服务器。升级前没有来源元数据的旧文件采用保守数量保护，首次减少需人工确认。

### 怎样自定义规则？

将模板复制为 `~/.config/miobridge/template.user.yaml` 后修改；存在时优先使用，配置页显示生效路径。升级保留已有模板，新官方版本写入 `template.yaml.new`，可自行对比合并。输出文件名固定为 `clash.yaml`。

### 怎样迁移和备份？

停止控制台后备份整个 `~/.config/miobridge`，保护好其中的令牌和 SSH 密钥。目标机安装相同或更新版本、恢复目录权限、更新公网地址、启动控制台并运行 doctor。Agent 配置位于其运行用户的 `~/.config/miobridge-agent`，根据服务用户一并备份。

### 如何设置定时生成与通知？

订阅页提供频率预设和标准五段 Cron（支持范围、列表、步长以及星期 0/7），按 `app.timezone` 计算，显示下一次执行时间。开关即时保存，其余草稿点击保存。Webhook 可选择 generic、Telegram、Bark 或企业微信模板，Telegram 还需 chat_id；配置事件白名单，测试发送后查看投递历史。失败最多重试三次，历史不保存令牌和响应正文。

### 为什么客户端导入后无法连接？

先确认订阅地址使用公网域名、正确令牌及 HTTPS；再检查代理协议端口和协议配置。订阅下载成功仅表示文件可访问，不代表每条代理线路连通。二维码在本地生成，不会发送到第三方服务。
